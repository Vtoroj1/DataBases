Вариант 3: Информационная система университета

Описание предметной области

Информационная система университета предназначена для учёта факультетов, групп, студентов, преподавателей, дисциплин и успеваемости.
Основные сущности:

Факультет - имеет название (уникальное) и ректора.

Группа - принадлежит факультету, имеет номер курса (1–4) и количество студентов.

Студент - учится в группе, имеет уникальный email, дату рождения.

Преподаватель - имеет уникальный email, учёное звание, кафедру.

Дисциплина - читается преподавателем, имеет семестр.

Ведомость - связывает студента и курс, хранит оценку (2–5).

Связи:

Факультет 1 - M Группа

Группа 1 - M Студент

Преподаватель 1 - M Дисциплина

Студент M - M Курс (через Ведомость)

Проектные решения

Все таблицы имеют первичные ключи.

Неключевые атрибуты зависят только от первичного ключа (2НФ) и не зависят транзитивно от других неключевых атрибутов (3НФ).

Например, в register оценка зависит от пары (студент, курс), а не от других полей.

В groups название группы уникально в рамках факультета - составное ограничение UNIQUE.

Использованы подходящие типы PostgreSQL: BIGSERIAL, VARCHAR, DATE, BIGINT.

Правила ON DELETE:

CASCADE - при удалении факультета удаляются его группы; при удалении студента/курса удаляются записи в ведомости.

SET NULL - при удалении группы студент остаётся без группы; при удалении преподавателя дисциплина остаётся без преподавателя.
